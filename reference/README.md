# Paper reference material

These four unmodified files were downloaded from
https://github.com/snu-ccl/FHE-MP-CNN at commit
a752630b1da3c7ed9e5f7f7a7f9aa817db720fdd for local algorithm research.
They are not compiled or linked into this project. The source tree has a license
for its bundled modified Microsoft SEAL directory; no repository-wide license
for these application files was found in the inspected tree. Do not conflate
that SEAL license with the Cheddar MIT license in the project root.

The new implementation was written against Cheddar's public primitives and the
independently tested slot formulas. Source correspondence is recorded in
../docs/ALGORITHM_MAPPING.md.
